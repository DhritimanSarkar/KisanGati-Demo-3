# SIH Demo Flow

1. Open the Vercel URL.
2. Show the 12-language login screen.
3. Select Farmer and register a crop.
4. Show the generated digital token.
5. Log in with mobile + token.
6. Show slot information and live queue.
7. Show weather assistance.
8. Show AI assistant using the farmer's token/context.
9. Log out.
10. Log in as Admin.
11. Advance the shared queue.
12. Open shipment/GPS tracking.
13. Update a procurement stage.
14. Show Lot Trace progression.
15. Record an explainable rejection if demonstrating the rejection workflow.
16. Return to the farmer account and show the updated read-only status.
17. Open `/api/health` to demonstrate Flask-to-Supabase connectivity.
